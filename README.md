一，规则
对象：应届生
针对岗位：通用互联网产品经理，AI产品经理，广告产品经理，推荐产品经理
- 简历解析：每份简历首次上传或更新时调用，保存解析结果。
- JD 解析：每个新的 JD 解析一次，后续复用。
- 面试蓝图：每次面试生成一次，保存题目及其考察目标。
- 动态追问：只有命中追问规则时才调用模型。
- 最终评价：面试结束后统一调用，批量评价所有回答。
- 失败重试：限制重试次数，避免接口故障造成重复扣费。
